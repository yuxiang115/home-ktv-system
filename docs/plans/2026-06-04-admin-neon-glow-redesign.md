# Admin 发光控制台重构设计与实施计划

**目标：** 将 HomeKTV 后台管理界面从浅色企业后台改为暗底、高饱和发光色、雾面卡片、边缘高光和柔和阴影组成的科技音乐控制台。

**范围：** 先聚焦 Web Admin 的视觉和布局完整重构，不改变核心业务流程。必要时只做轻量结构增强，不引入新后端 API。

## 设计系统

- 背景：深黑蓝 `#050713` / `#0a1024`，叠加低透明电蓝、洋红、萤光绿光洗和细网格。
- 主文字：高对比实色 `#f8fbff`，辅助文字 `#9da9c9`，避免文字被光晕吞噬。
- 发光色：电蓝 `#29d8ff`、洋红 `#ff3df2`、萤光绿 `#6cff9d`、玫红危险色 `#ff4d7a`。
- 卡片：低透明深色雾面背景，1px 半透明边框，内外发光混合；重要卡片使用顶部或左侧高光线。
- 交互：hover 光晕扩散并提高亮度，active 轻微下沉并收敛阴影，过渡 150-220ms。
- 动效：只给背景光场使用柔和呼吸；尊重 `prefers-reduced-motion`。

## 页面改造

### 顶部导航

- `admin-app-frame` 增加全局光场背景。
- `admin-mode-tabs` 改为 sticky 半透明玻璃导航。
- 当前 tab 使用电蓝/洋红渐变和多层阴影。
- 语言切换改为小型发光 segmented control。

### NAS 曲库页

- `admin-header` 改为 hero 控制台标题区，增加状态光源线。
- `ktv-index-metrics` 改为发光指标卡，突出曲库总量、探测覆盖率、缺失数。
- 表格区域改为雾面 panel，行 hover 有细光边。
- 搜索预览结果改为发光列表，版本路径使用暗色 code pill。

### 房间状态页

- 摘要卡改为 5 个状态舱，在线/离线通过文字和发光强度区分。
- 当前歌曲、队列、在线任务、最近事件统一使用 panel 视觉语言。
- 任务状态 chip 使用不同色彩光效，操作按钮沿用全局按钮系统。

### 宽屏与移动

- 宽屏维持高信息密度，卡片最大宽度受控。
- 中屏改为两列。
- 680px 以下改为单列，顶部 tab 可横向滚动，文本不重叠。

## 实施步骤

1. 重构 `apps/admin/src/App.tsx` 顶层 chrome，增加品牌/状态装饰元素。
2. 轻量增强 `SongCatalogView.tsx` 和 `RoomStatusView.tsx` 的 className，用于视觉定位，不改变数据流。
3. 重写 `apps/admin/src/App.css` 的全局变量、背景、导航、卡片、按钮、状态 chip、表格和响应式。
4. 补充少量测试，确保新 chrome 和关键区域仍可访问。
5. 运行 Admin 单测、build、diff 检查。
