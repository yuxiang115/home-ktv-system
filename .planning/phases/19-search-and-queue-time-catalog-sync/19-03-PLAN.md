    Export:

    ```ts
    export interface ExecuteIndexedAddQueueEntryInput {
      commandId: string;
      roomSlug: string;
      sessionVersion: number;
      deviceId: string;
      indexedAssetId: string;
      cookieHeader: string | undefined;
    }

    export class PgIndexedQueueCommandService {
      constructor(options: {
        pool: Pool;
        config: ApiConfig;
        assetGateway: AssetGateway;
        createRepositories?: (db: QueryExecutor) => RuntimeRepositories;
      })
      executeIndexedAddQueueEntry(input: ExecuteIndexedAddQueueEntryInput): Promise<CommandExecutionResult>
    }
    ```

    Implementation steps inside `executeIndexedAddQueueEntry`:

    1. `const client = await pool.connect()`.
    2. `await client.query("BEGIN")`.
    3. `const repositories = createRepositories(client)`.
    4. Resolve room by slug. If missing, `ROLLBACK` and return rejected `ROOM_NOT_FOUND`.
    5. Restore control session with `restoreControlSession` using transaction-bound `repositories.controlSessions`.
    6. Construct `new PgKtvCatalogSyncService(client)` and call `syncIndexedAsset({ indexedAssetId })`.
    7. Call `executeRoomCommand` with:

       ```ts
       type: "add-queue-entry",
       payload: {
         songId: sync.songId,
         assetId: sync.assetId,
         queueAdmissionSource: "ktv-index",
         indexedAssetId
       }
       ```

    8. `COMMIT` if no exception is thrown.
    9. `ROLLBACK` on any exception.
    10. Convert `KtvCatalogSyncError` into rejected command results:

        - `KTV_INDEX_ASSET_STALE` -> code `KTV_INDEX_ASSET_STALE`, message `索引已失效`
        - `KTV_INDEX_FILE_UNREADABLE` -> code `KTV_INDEX_FILE_UNREADABLE`, message `文件不可读`

    11. Always `client.release()` in `finally`.
